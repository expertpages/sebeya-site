# СЕБЕЯ — сайт путеводителя «Расставашка»

Лендинг с двумя кнопками оплаты ЮKassa (без корзины). Чистый HTML/CSS/JS
без зависимостей — можно залить на любой хостинг или GitHub Pages как есть.

Бренд «Себея» — «вернуть себе себя»: путеводители, которые помогают
переживать тяжёлые жизненные периоды и возвращаться к себе.

## Структура

- `index.html` — единственная страница: лендинг, два товара, сравнение с психологом
- `js/main.js` — конфиг с ценами и ссылками на оплату
- `img/logo.png` — логотип («себя» с медной петлёй)
- `img/logo.svg` — иконка вкладки (медный круг с буквой «Я»)
- `img/cover.jpg` — обложка путеводителя
- `design-prompts.md` — промты для генерации иллюстраций (ChatGPT и др.)

## Как работает покупка (обновлено 28.10.2026)

Кнопки «Купить» на лендинге ведут на **страницы-чекауты** — перед оплатой
собирается почта (PDF) или адрес и телефон (печатная тетрадь), чтобы не
терять тех, кто не завершил оплату:

```
index.html → checkout-notebook.html / checkout-pdf.html → ЮKassa
```

В **`js/main.js`** у каждого товара два поля:

```js
products: {
  pdf:      { ..., url: "checkout-pdf.html",      payUrl: "ССЫЛКА_НА_СЧЁТ_990_РУБ" },
  notebook: { ..., url: "checkout-notebook.html", payUrl: "ССЫЛКА_НА_СЧЁТ_1990_РУБ" },
},
```

- `url` — куда ведёт кнопка на лендинге (страница-чекаут);
- `payUrl` — фиксированный счёт ЮKassa, его открывает чекаут после отправки формы.

## Приём заявок с чекаутов (Google-таблица + Telegram)

Код приёмника — **`apps-script-receiver.gs`**: вставить в Apps Script над
Google-таблицей, заполнить токен бота и chat_id, развернуть как
веб-приложение (доступ «Все») и вставить полученный URL в константу
`CHECKOUT_ENDPOINT` в **`js/checkout.js`**. Пока она пуста — заявки не
записываются, но редирект на оплату работает.

Каждая заявка: строка в таблице (имя, телефон, почта, адрес, доставка,
источник) + уведомление в Telegram. В таблице есть колонка «Оплатила?» —
по ней отслеживаем брошенные корзины для дожима.

## Что ещё можно быстро поменять (в `js/main.js`)

- Цены: `products.pdf.price`, `products.notebook.price`
- Названия товаров: `products.*.name`
