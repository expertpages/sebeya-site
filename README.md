# СЕБЕЯ — сайт путеводителя «Расставашка»

Лендинг с двумя кнопками оплаты ЮKassa (без корзины). Чистый HTML/CSS/JS
без зависимостей — можно залить на любой хостинг или GitHub Pages как есть.

Бренд «Себея» — «вернуть себе себя»: путеводители, которые помогают
переживать тяжёлые жизненные периоды и возвращаться к себе.

## Структура

- `index.html` — единственная страница: лендинг, два товара, сравнение с психологом
- `js/main.js` — конфиг с ценами и ссылками на оплату
- `img/logo.png` — логотип («себя» с медной петлёй)
- `img/logo.svg` — иконка вкладки (медный круг с буквой «Я»)
- `img/cover.jpg` — обложка путеводителя
- `design-prompts.md` — промты для генерации иллюстраций (ChatGPT и др.)

|---|---|---|

| Печатная тетрадь | 1 990 ₽ (старая 3 990 ₽) | `CONFIG.products.notebook.url` |

## Как подключить оплату ЮKassa

В **`js/main.js`** вставь ссылки в параметры `url` у обоих товаров:

```js
products: {
  pdf:      { ..., url: "ССЫЛКА_НА_СЧЁТ_990_РУБ" },
  notebook: { ..., url: "ССЫЛКА_НА_СЧЁТ_1990_РУБ" },
},
```

У каждой кнопки своя ссылка — фиксированный счёт из личного кабинета ЮKassa.
Сейчас обе ссылки уже вставлены и оплата работает.
Плейсхолдер `{SUM}` (заменится ценой товара) поддерживается на случай ссылки
с изменяемой суммой. Пока ссылка пустая, кнопка сообщает, что оплата скоро заработает.

## Что ещё можно быстро поменять (в `js/main.js`)

- Цены: `products.pdf.price`, `products.notebook.price`
- Названия товаров: `products.*.name`
