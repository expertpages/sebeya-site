# ТОЧКА — сайт тетради «Расставашка»

Лендинг → корзина (email + оплата Robokassa). Чистый HTML/CSS/JS без зависимостей —
можно залить на любой хостинг или GitHub Pages как есть.

## Страницы

- `index.html` — лендинг тетради «Расставашка» (цена: 3 990 ₽, старая: 7 800 ₽)
- `cart.html` — корзина: тетрадь, email покупателя и кнопка оплаты

## Оплата

Кнопка оплаты ведёт на фиксированный счёт Robokassa на **4 340 ₽**
(1 тетрадь 3 990 ₽ + доставка 350 ₽). Ссылка хранится в одном месте —
**`js/main.js`**, параметр `ROBOKASSA_URL`:

```js
ROBOKASSA_URL: "https://auth.robokassa.ru/merchant/Invoice/z8StKFl5gkeg6BWX4uOOnQ"
```

Чтобы поменять счёт — просто замени ссылку там. Если позже появится ссылка
с изменяемой суммой, можно использовать плейсхолдер `{SUM}` — он автоматически
заменится итоговой суммой корзины.

Количество в корзине сейчас зафиксировано на 1 шт., чтобы сумма заказа всегда
совпадала со счётом.

## Email покупателя

Email вводится в корзине перед оплатой и сохраняется в localStorage браузера
(`tochka_email_v1`). Так как сайт статический, email пока никуда не отправляется —
при необходимости его можно передать в CRM/бота (например, через Robokassa API
или простой серверный скрипт).

## Что можно быстро поменять (всё в `js/main.js`)

- Ссылка на оплату: `ROBOKASSA_URL`
- Цена и старая цена: `product.price`, `product.oldPrice`
- Стоимость доставки: `delivery.price`
