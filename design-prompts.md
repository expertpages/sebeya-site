# Промты для генерации дизайна сайта «Себея»

Генерируй иллюстрации в ChatGPT (или Midjourney/DALL·E) по этим промтам.
Каждый промт самодостаточный — можно копировать целиком.

## ⚠️ Общие требования ко всем картинкам

- **Без текста и букв!** Генераторы плохо рисуют кириллицу — все надписи мы наложим сами.
- **Формат:** иллюстрации — **PNG с прозрачным фоном**, фоны — **JPG или PNG**, не меньше 1920 px по ширине.
- **Стиль:** минимализм, тонкие непрерывные линии (line art), много воздуха, лёгкая акварельная дымка. Никаких 3D, фотореализма и хаотичных узоров.
- **Палитра бренда:**
  - медь/терракота — `#C78A67` (главный акцент, как петля в логотипе)
  - тёмная медь — `#A5623A`
  - чернильный сине-серый — `#556070` (второстепенные линии)
  - нежно-голубоватый фон — `#F2F7FA`
  - мягкий сине-серый — `#E7EEF4`
- Картинки должны выглядеть как работы одного художника: одна толщина линий, одна рука.

## 1. Фон для всей страницы (тело сайта)

**Формат:** JPG или PNG, 1920×2560 и больше (вертикальный), можно тайлиться.

```
Минималистичный фоновый дизайн для сайта о психологической самопомощи.
Очень светлый, почти белый фон цвета #F2F7FA (нежно-голубоватый белый).
По фону едва заметные акварельные разводы в пастельных оттенках
медно-терракотового (#C78A67) и сине-серого (#E7EEF4), прозрачность 5–8%,
чтобы текст на фоне читался идеально. В левом нижнем и правом верхнем углу —
тонкие декоративные линии-завитки, напоминающие петлю из медной проволоки
(одна непрерывная линия, которая закручивается в маленькую петлю и уходит
за край). Много воздуха, минимум деталей, ничего не мешает чтению.
Без текста, без букв, без логотипов, без людей. Плоский стиль, line art.
```

## 2. Иллюстрация для hero-блока (вертикальная, справа от заголовка)

**Формат:** PNG с прозрачным фоном, 900×1200 (портретная).

```
Тонкая минималистичная иллюстрация одной непрерывной медной линией (line art):
петля из проволоки цвета меди #C78A67 закручивается в маленькое кольцо-петельку
(как завиток каллиграфии, символ «начать сначала»), затем линия плавно
превращается в путь-дорожку, которая вьётся вверх по диагонали через всю
картинку и заканчивается маленьким солнцем в правом верхнем углу.
Вдоль пути 3–4 маленьких нарисованных той же линией символов: бумажный
самолётик, конверт с письмом, раскрытая тетрадь, маленькое сердце, из
которого вырастает цветок. Всё на прозрачном фоне, без заливок,
только линия толщиной 3–4 px, цвет меди, лёгкая акварельная тень под
некоторыми элементами. Без текста и букв. Изящно, женственно, спокойно.
```
